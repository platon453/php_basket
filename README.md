## Модуль Корзины (php_basket)

Этот документ описывает архитектуру и принципы работы модуля корзины, который был интегрирован в структуру основного проекта. Модуль обеспечивает полный функционал от добавления товаров в корзину до оформления заказа и администрирования.

---

### 1. Архитектура и Структура Файлов

Модуль спроектирован по принципу разделения логики (Function), точек входа (API) и отображения (Templates). Это обеспечивает гибкость и простоту поддержки.

- **`/api/`** - Точки входа для AJAX-запросов.
  - Каждый файл в этой директории (например, `BasketPlaceOrder.php`) отвечает за одно конкретное действие.
  - Его задача — принять запрос, подключить необходимую бизнес-логику из папки `/function/`, вызвать ее и вернуть ответ в формате JSON.

- **`/function/`** - Бизнес-логика модуля.
  - Здесь находится "мозг" всего функционала. Файлы содержат функции, которые выполняют основные операции: работу с сессией, взаимодействие с базой данных, расчеты и т.д.
  - Также здесь лежат файлы-обработчики для отображения страниц (например, `BasketShowCart.php`), которые вызываются роутером.

- **`/routes/`** - Маршрутизация.
  - Определяет, какой код будет выполнен для каждого URL.
    - `list.php`: Сопоставляет URL (например, `/cart`) с уникальным ID (например, `148`).
    - `actions.php`: Использует ID из `list.php` для вызова нужного файла-обработчика из `/function/`.
    - `titles.php`: Устанавливает заголовок `<title>` для каждой страницы.

- **`/assets/`** - Статические ресурсы.
  - Ресурсы модуля имеют префикс `basket_` для избежания конфликтов имен.
    - `/css/basket_styles.css`: Стили для клиентской части (корзина, оформление заказа).
    - `/css/basket_admin.css`: Стили для панели администратора.
    - `/js/basket_script.js`: Скрипты для клиентской части.
    - `/js/basket_admin.js`: Скрипты для панели администратора.
    - `/img/`: Изображения, используемые в модуле.

- **`/templates/basket/`** - Файлы верстки (шаблоны).
  - Все HTML-фрагменты и страницы модуля хранятся в этой подпапке, чтобы не смешиваться с шаблонами основного проекта. Файлы имеют расширение `.php`.

- **`/config/`** - Конфигурация.
  - `db.php`: Файл для подключения к основной базе данных проекта. (В текущей реализации используется временный файл с подключением к SQLite).

- **`/reserv/`** - Резервные копии.
  - Содержит оригинальные HTML-файлы верстки для справки.

### 2. Основные Принципы Работы

#### Отображение страницы (например, `/cart`)

1.  Пользователь заходит на `http://localhost:8000/cart`.
2.  Главный `index.php` получает запрос.
3.  Он находит в `routes/list.php` соответствие: `cart` => `148`.
4.  Затем в `routes/actions.php` выполняется `case 148`, который подключает и вызывает функцию `BasketShowCart()` из `function/BasketShowCart.php`.
5.  Функция `BasketShowCart()` подключает файл верстки `templates/basket/cart.php`, который и видит пользователь.

#### Обработка AJAX-запроса (например, очистка корзины)

1.  JavaScript на клиенте выполняет `fetch('/api/BasketClear.php')`.
2.  Сервер напрямую выполняет код в файле `api/BasketClear.php`.
3.  Этот файл подключает `function/BasketClear.php` и вызывает функцию `BasketClear()`, которая очищает `$_SESSION['cart']`.
4.  `api/BasketClear.php` возвращает JSON-ответ с обновленным состоянием корзины.

### 3. База Данных

- **Подключение**: Модуль использует стандартное подключение к БД проекта через `require_once 'config/db.php'`.
- **Таблицы**: Для избежания конфликтов, таблицы модуля имеют префикс `basket_`.
  - `basket_orders`: Основная информация о заказах.
  - `basket_order_items`: Товары, входящие в каждый заказ.

**Схема таблиц (SQLite):**
```sql
CREATE TABLE basket_orders (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    customer_type VARCHAR(255),
    delivery_type VARCHAR(255),
    customer_details TEXT,
    legal_details TEXT,
    total_price DECIMAL(10, 2)
);

CREATE TABLE basket_order_items (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    order_id INT,
    product_id INT,
    product_title VARCHAR(255),
    quantity INT,
    price_per_item DECIMAL(10, 2),
    FOREIGN KEY (order_id) REFERENCES basket_orders(id) ON DELETE CASCADE
);
```

### 4. Панель Администратора

- **Доступ**: `/admin_panel`
- **Авторизация**: Реализована через проверку IP-адреса пользователя. Список разрешенных IP находится в файле `admin_list.php`.
- **Функционал**:
  - Просмотр всех оформленных заказов.
  - Просмотр детальной информации по каждому заказу (состав, данные покупателя).
  - Полная очистка базы данных заказов.

---

### 5. Локальный Запуск и Тестирование

1.  **Настройка БД**: Если база данных не создана, выполните в терминале `php setup_database.php`. Это создаст файл `database.sqlite` с нужной структурой.
2.  **Доступ в админку**: Добавьте свой IP-адрес в файл `admin_list.php`.
3.  **Запуск сервера**: В корневой директории проекта выполните команду:
    ```bash
    php -S localhost:8000 -t .
    ```
4.  **Наполнение корзины для теста**: Чтобы быстро добавить товары в корзину, откройте консоль разработчика в браузере и выполните:
    ```javascript
    fetch('/api/BasketDebugFill.php')
      .then(res => res.json())
      .then(data => {
        console.log('Корзина наполнена!', data);
        window.location.reload();
      });
    ```
